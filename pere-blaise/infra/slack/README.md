# Slack — application existante à réutiliser

Vérifier l'app existante `Hermes — Père Blaise`, le workspace et le canal privé `#agent-pere-blaise`. Ne la supprimer ou recréer qu'après décision du propriétaire. Pour `envoie`, les scopes bot sont `app_mentions:read`, `chat:write`, `files:write`. Pour recevoir `tiens` avec fichier dans ce canal privé, ajouter `files:read` et `groups:history`, puis les événements `app_mention` et `message.groups` ; réinstaller l'app si Slack le demande. Le broker ignore les événements `message.groups` sans fichier, hors canal configuré ou sans mention exacte du bot ; il accepte le partage de fichier comme message ordinaire ou avec le sous-type historique `file_share`. `groups:history` donne néanmoins à l'app accès à l'historique du canal privé : vérifier que sa composition et sa rétention conviennent au propriétaire. Socket Mode exige `connections:write` sur son token d'app. Les IDs, allowlists et tokens réels sont privés. Tester un seul consommateur, `tiens` autorisé, les refus canal/utilisateur, un fichier, un timeout et l'absence de DM avant activation.
