# Slack — application existante à réutiliser

Vérifier l'app existante `Hermes — Père Blaise`, le workspace et le canal privé `#agent-pere-blaise`. Ne la supprimer ou recréer qu'après décision du propriétaire. Ajouter le scope bot `files:write` aux scopes `app_mentions:read` et `chat:write`, puis réinstaller l'app si Slack le demande. Socket Mode exige `connections:write` sur son token d'app. Le broker répond dans le fil de la mention et utilise `files.getUploadURLExternal` puis `files.completeUploadExternal` pour les pièces jointes. Les IDs, allowlists et tokens réels sont privés. Tester un seul consommateur, la mention autorisée, les refus canal/utilisateur, un fichier, un timeout et l'absence de DM avant activation.
