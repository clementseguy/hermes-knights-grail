# Réseau

Hermes et broker communiquent sur le réseau Compose privé ; aucun port n'est publié. Le réseau `outbound` permet OAuth/modèle et API Telegram/Slack. Le propriétaire a accepté le 14 octobre 2026 l'absence de pare-feu Docker à allowlist de domaines pour ce Mac personnel ; revue proposée le 14 avril 2027. Aucun filtrage sortant par domaine n'est en place. Les clients du broker utilisent `api.telegram.org`, `slack.com/api/`, un WebSocket `wss` sous `.slack.com` validé à l'exécution, et une URL d'upload `https` sous `.slack.com`. Les destinations du fournisseur dans Hermes épinglé sont à vérifier lors des mises à jour. Les identités et secrets des canaux restent uniquement dans le broker.
